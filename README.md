# <span style="color:#8fb89f">Zhijian Reader</span>

Zhijian Reader，纸间阅读器，本地优先的离线电子书 Web 应用。

所有书籍、阅读进度、书签与配置仅保存在浏览器本地，不会上传至外部服务器。
无需后端服务，仅单个静态 HTML 文件，可直接本地打开，或部署至 GitHub Pages。

## 功能
- 书架管理，支持 TXT、EPUB、PDF 导入，支持 ZIP 批量导入
- 阅读进度记录、目录跳转、书签、书摘卡片
- 阅读样式自定义：字号、行间距、纸张配色、自定义字体
- 主题控制，支持手动切换深浅色，或跟随系统主题自动变化
- 阅读数据备份与恢复
- 移动端与桌面端自适应布局

## 使用
1. 下载 index.html
2. 浏览器直接打开，或部署到静态网页服务
3. 导入书籍开始阅读

## 部署
本项目仅依赖静态资源，支持 GitHub Pages、Vercel、Netlify 等任意静态托管平台。
将仓库设置为 Pages 源，指向 main 分支根目录即可。

## 限制
- 数据存储依赖浏览器 IndexedDB，清除浏览器数据会丢失本地书籍
- 大体积书籍导入时，性能取决于当前浏览器环境
- 不支持 DRM 加密电子书
